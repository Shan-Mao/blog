AI 工具

日常对话、写作、编程时会用到的模型和平台

  • 🤖 Claude 长文本理解和写作都很稳，写代码也好用 ↗
  • C ChatGPT 通用对话助手，日常问问题基本够用 ↗
  • D DeepSeek 国内可直接访问，中文和推理表现不错 ↗
  • G Gemini Google 的模型，查资料时配合搜索用 ↗

开发工具

写代码、查文档、调格式时用得上的

  • 🐙 GitHub 代码托管，顺便也是找轮子的地方 ↗
  • V Visual Studio Code 主力编辑器，插件生态最省心 ↗
  • S Stack Overflow 报错信息直接搜，多半有人踩过 ↗
  • R RegExr 在线调试正则，边写边看匹配结果 ↗
  • C Can I use 查 CSS/JS 特性的浏览器兼容情况 ↗
  • C Carbon 把代码片段导出成好看的图片 ↗

科研工具

查文献、管理引文、写作排版

  • G Google Scholar 找文献的起点，看引用关系很方便 ↗
  • a arXiv 预印本，追最新进展基本靠它 ↗

  • Z Zotero 文献管理和自动生成引用 ↗

  • S Squoosh 在线压图片，本地处理不上传 ↗
